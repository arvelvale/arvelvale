### Projects

**[Orrery](https://github.com/arvelvale/orrery)** — every Claude Code, Kimi Code, DSH, Codex,
OpenCode, Z Code and Antigravity session in one window: normalized token accounting, disk usage,
session cleanup, and one local model proxy for all of them. Rust + Tauri, no telemetry,
nothing leaves your machine.

state in sync.
